# backend-main-gfsuhbulmw RESTful API Service

##1. Environment
- Maven 3.0 이상
- JAVA 17
- SpringBoot 3.0.11
- PostgreSQL 15.3

##2. Project Run
- Run Server

    `{SRC_ROOT}$ mvn spring-boot:run`

##3. Project Build
- Clean: 

    `{SRC_ROOT}$ mvn clean`

- Build Package

    `{SRC_ROOT}$ mvn package`
    
    `{SRC_ROOT}$ mvn package -Prelease`
    
##4. Versions
- Search

  `ElasticSearch 8.6.2`

  `Kibana 8.6.2`

  `Logstash 8.6.2`
